## Adversarial (A)

### A1
- **Where:** brief addendum example 26 case c; prd.md FR-33 'The hollow win still holds' (l.835); PRD addendum 'Refined while applying (OQ-19)' (l.447)
- **Problem:** 'Strongest activity allowed' modelled as (stress -5, social +10), but FR-53/rule 12 allow ±10 on stress; with (-10,+10) the chaser ends at 42/46/37, not 41/44/37
- **Fix:** Recompute 26c at configured limits (±10 per activity, ±15 a month); replace figures in FR-33, example 26c and addendum, or drop 'strongest allowed'; state the bound comes from the caps
- **Consequence:** Unit tests encode the wrong bound; OQ-8 tuning relies on a smaller margin than stated (4 points to 50 on goal 2, not 6)

### A2
- **Where:** prd.md FR-9 'Reachable'/'Checked with real costs' (l.406-407); brief addendum example 20 (l.161)
- **Problem:** Goal 1 shown reachable only with no activities; reference run clears NOK 100,000 by NOK 6,928; ~NOK 110-160/month activity spend erases that; example 25's NOK 650 month from month 19 misses by ~NOK 22,000
- **Fix:** Add a 'careful player with modest leisure' reference run (free + cheapest paid basic activity monthly); make goal 1 and 2 results pass/fail; state the activity budget the targets assume; retune if it fails
- **Consequence:** Engaged careful players miss goal 1; 'goal not reached' becomes normal for players who use the new loop

### A3
- **Where:** brief addendum rule 12 (l.72), example 17b (l.128); prd.md FR-47 25 h limit (l.649), FR-52 (l.1017-1018), OQ-8 note (l.1280)
- **Problem:** Threshold 50, the 25 h cliff and 17b were calibrated without activities; a 26 h player still has 2 slots worth ~10 points/month, lifting 17b's 41 to a win; FR-52 'never zero' holds only while divisor <= 20
- **Fix:** Seeded wellbeing check filling slots with best free activities for 17b (25 h, 26 h) and 21c; make 26c a failing check on catalog/cap/divisor/threshold change; constrain divisor
- **Consequence:** Hollow-win lesson and the 25 h hint silently stop working once real activities are written

## Edge cases (E)

### E1
- **Where:** prd.md FR-49 L469, FR-53 'Applied at continue' L1035, FR-41 L924; brief addendum rule 1, rule 8
- **Problem:** Planned activities applied at continue make a rule 8 trigger true again, incl. months 59-60
- **Fix:** on continue: simulate plan; if any trigger flips true (paying from account or savings raises net debt, card spend adds debt), warn and require confirm; show post-plan trigger state in crisis months and months 59-60
- **Consequence:** Player clears month-60 crisis, plans a concert, continues, and gets the Loss ending

### E2
- **Where:** prd.md FR-9 'progress during play' L409, FR-57 'Life goal' L625; brief addendum rule 13
- **Problem:** Goal progress shown before continue excludes planned activity costs in months 49-60
- **Fix:** goal progress and lowest-available-money display = state after applying the current plan; flag when the plan takes net savings or month-end buffer below target
- **Consequence:** Player exactly at buffer or NOK 100,000 target misses goal without warning

### E3
- **Where:** prd.md FR-45 'Activities' L617 vs FR-53 'Applied at continue' L1035, FR-26 L719, FR-23 'Card' L684
- **Problem:** Card-payable activity with card on: account first (FR-45) or card first (FR-26/FR-23)?
- **Fix:** state one order for activities, e.g. card first if card-payable and it fits whole, else account then savings; no split between card and account
- **Consequence:** Engines differ on savings drain, card balance, and interest cause links

### E4
- **Where:** prd.md FR-53 'Applied at continue' L1035, NFR-7 activity refusals L1177
- **Problem:** Flags change after placement, e.g. moped sold, leaving an ineligible activity planned
- **Fix:** at continue, re-check age range, required and blocking flags for each planned activity; drop failing ones with a note, same as unaffordable ones
- **Consequence:** Activity applied that NFR-7 would refuse to place; flag rules bypassed

### E5
- **Where:** PRD addendum Message schema 'links to' check L149; prd.md FR-55 'Who can get one' L1070
- **Problem:** Linked activity's age range may be narrower than invitation's; flags never cross-checked
- **Fix:** check: target age range covers the message range, and message flags imply target flags; or draw an invitation only when its activity is placeable now
- **Consequence:** Player gets an invitation whose activity cannot be placed

### E6
- **Where:** prd.md FR-18 table L550-562 and consequence L565, FR-17 L517, FR-55 L1071; PRD addendum offer table L70 (credit card month 39), message schema 'when' L150
- **Problem:** FR-18 rows lacking offer months still need offer messages; credit card 37 vs 39
- **Fix:** give every FR-18 row an explicit offer month (one value for the credit card), or exempt rows with no offer month from the offer-message requirement
- **Consequence:** Content check unsatisfiable; credit card message month differs between PRD and addendum

### E7
- **Where:** prd.md FR-55 'Offers always arrive' L1071, FR-48 'Blocked for another reason' L578
- **Problem:** Player doesn't qualify in the offer month (e.g. no steady wage) but qualifies later
- **Fix:** offer arrives in the first month at or after its offer month in which the player qualifies, or arrives anyway showing what is missing
- **Consequence:** Credit card or full-time job offer message never arrives for that player

### E8

- **Problem:** Three or more offers fill the cap; event message and info messages dropped
- **Fix:** exempt the event message from the cap like offers; give state-triggered bank messages a kind and priority, and defer them instead of dropping
- **Consequence:** Active month's highlight event or bank message silently missing from the phone

### E9

- **Fix:** define progress % per goal or limit to goal 1; one message for the highest threshold crossed; one-off per target, reset when re-pinned
