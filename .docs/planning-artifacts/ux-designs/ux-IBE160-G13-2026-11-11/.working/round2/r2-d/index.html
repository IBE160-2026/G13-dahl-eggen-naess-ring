Minst 8 tegn.

Bare for deg, ingen andre ser det. Det trenger ikke være det ekte navnet ditt. Det er dette folk i spillet kaller deg: «Hei Mak!»

Kort om spillet og hva vi lagrer

Vi lagrer e-posten, passordet (kryptert), kallenavnet og spillet ditt. Ikke navn, alder eller hvor du bor. Alle tall i spillet er laget for å lære, ikke ekte råd om pengene dine.

Du kan slette brukeren og alt som er lagret når du vil.
